# 🀄 麻将钱账 v7.1 — 香港麻将专用番制

基于 v7，**删除中国国标／世界麻将 MCR 的计分切换和 81 种番表**。保留 v6/v7 的 Firebase 共享房间、密码、管理员、分享链接、换人、排名、任意撤销、RM 结算及动态麻将牌例。

## 这次改了什么

- **只有一个番制**：香港麻将（HK）。无需再选择 HK/MCR。
- **算番仍是 Optional**：关闭后，原本的胡牌、点炮、飞、明杠、暗杠金额不受影响。
- 香港参考番表可搜索和看动画牌谱，也可输入 14 张牌识别部分常见牌型（须牌友核对）。
- 香港常见示例：对对糊 3 番、混一色 3 番、清一色 7 番、十三幺 13 番；特殊牌型与花牌因桌规不同会有差异。
- 房间设置仍能调节「起糊番数、封顶、是否按番额外加价及每番 RM 金额」。默认最低起糊为 **0**，兼容牌友原本「只要能胡」的桌规；如需要更严格，可改 3。
- 已存在的旧 MCR 历史交易金额**保留原值，不会重算**；旧 MCR 分数不累计成香港番数。**原本使用 MCR 的房间，算番及番数加价会先自动停用，必须由牌友到「玩家／规则」手动保存香港番数设置才重新生效**；避免旧分制直接改算钱。升级后新的番记录只接受香港规则。

## 安装到现有 GitHub（无需重建 Firebase）

1. 从旧网页先导出所有房间 JSON 备份。
2. 将 ZIP 内 `index.html`、`app.js`、`fan.js`、`fan-data.js`、`fan.css`、`cloud-sync.js`、`.nojekyll` 和 `README.md` 上传到 GitHub Repository 根目录，覆盖旧版。
3. **保留 GitHub 上已经填好的 `firebase-config.js`，千万不要用示例文件覆盖。** 这次压缩包为避免误覆盖，**没有附带** `firebase-config.js`。
4. 这次 `fanConfig` 使用的字段与 v7 相同，**如果你已正确发布 v7 的 Firestore Rules，就不必为这次改动再次修改 Rules**。若仍使用 v6，必须按旧 v7 指引先允许 `fanConfig`；本 ZIP 不包含规则替换文件，以免误覆盖你的管理员 UID；请在原 Firebase Rules 的允许字段清单中加入 `fanConfig`，不要把它加入必填字段。
5. 刷新 GitHub Pages；进入房间 → 玩家／规则 →「开启本房间的算番功能」，保存后即可在「算番／牌谱」选牌型并套用。
6. 用两部手机实际测试开启与关闭、不同房间同步和记账。

## 计费约定

默认仍是：自摸其余三家各付 RM1；点炮者 RM2，另外两家各 RM1；飞每粒每家 RM1；明杠每家 RM2、暗杠每家 RM4（各房间可改）。

**默认只记录番数，不加钱。** 如果自己开启「按番额外加价」：对对糊 3 番，每番 RM0.50，点炮胡牌时，点炮者付 RM3.50，其他两家各 RM2.50；共 RM8.50。它是本 App 的**自订桌规公式**，不是香港麻将统一官方赔付表。

## 参考规则的限制

不同香港牌桌对「起糊」「封顶」「花牌」「七对」以及特殊天、地、人糊的分值有不同约定。普通牌型、门清与自摸可累积的条件也需要核对。14 张牌仅能识别部分结构，**不等同于自动判断所有吃碰杠及特殊成糊过程**；请由牌友确认后记账。
